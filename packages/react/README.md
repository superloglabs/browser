# @superlog/react

An error boundary, React 19 root error handlers, and React Router route
patterns for [`@superlog/browser`](https://www.npmjs.com/package/@superlog/browser).

```tsx
import { ErrorBoundary, instrumentRouter, reactErrorHandler } from "@superlog/react";
```

See the [repository README](https://github.com/superloglabs/browser#react).
